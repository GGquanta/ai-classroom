# 用 AI Skill 把产品材料变成销售宣讲话术

> 已整理为站点文章：`content/library/workflows/sales-pitch-script-skill.md`  
> 作者名称见同级 `readme.md`（klay）

把公司宣讲 PPT / 产品介绍，整理成给销售照着讲的话术：能讲完、讲圆。

## 何时使用

- 用户要基于 PPT/PDF/产品材料写宣讲话术、销售培训稿、对外讲稿

## 核心原则：展示三分，藏三分

| 可以写 | 不要写 |
| --- | --- |
| 公司定位、业务方向、适用场景 | 详细设计、核心工艺、部署图纸 |
| 原理点到为止（一句话说明「靠什么」） | 原理推导、算法细节、实现路径 |
| 关键指标（体积、速率、灵敏度等招牌数字） | 完整参数表、测试条件、友商细比 |
| 亮点（首创、抗攻击、项目背书） | 报价、商务条款、内部组织细节 |
| 标杆项目点名与方向 | 涉密项目细节、可复现的实施方案 |

## 工作流程

1. **吃透材料**：从 PPT/PDF/产品文档提取结构与要点（业务、产品、项目、资质团队）。
2. **定信息水位**：按上表筛选——保留方向、一句话原理、关键指标、亮点。
3. **写成连贯文章**：合成一整篇可照着念的口播文。
4. **加上文首使用要求**：按下方模板写入文首（可按公司名微调）。
5. **输出 Word**：微软雅黑、标题居中、正文首行缩进、1.5 倍行距；同时可保留 `.md` 源稿。

## 文首「使用要求」模板

文首必须包含（可按公司名微调）：

> 本话术供对外宣讲培训使用。使用要求如下：
>
> 一、可按本文连贯讲述，讲清原理方向、关键指标和亮点，不自行扩展更深技术细节和实施方案。
>
> 二、客户追问详细设计、报价、部署图纸、核心工艺时，统一回复：「这个我们安排技术同事单独对接。」
>
> 三、本话术用于对外介绍，不作为内部核心技术培训材料。

## 文章结构（默认）

按这个顺序组织成若干自然段，不要「第 N 页」标题：

1. **开场**：公司全称、一句话定位、本次讲什么
2. **背景**：政策/行业需求 → 我们解决什么（安全、感知等）
3. **业务与产品总览**：芯片/模块底座 + 几条产品线
4. **分产品**：每条线一段——场景 → 一句话原理 → 关键指标 → 亮点 → 适用边界
5. **标杆项目**：点名客户/级别与方向，细节「另行介绍」
6. **资质与团队**：专利/认证/奖项数字；创始人、科学家各一两句
7. **收尾**：地址 + 引导客户选方向 + 转对口对接

## 原理 / 指标 / 亮点写法

- **原理**：一句，例如「利用真空能量涨落生成真随机数」「捕捉极微弱光子信号」。
- **指标**：只留对外招牌数，例如体积约 0.7 cm³、速率 10Gbps 以上、检出限 0.1–1 ppb。
- **亮点**：首创、抗侧信道、芯片化可集成、已中标国家/省级项目等。

| --- | --- |

## AI 高效办公（补充）

- 固定模板（输入—结构—禁区—交付），少从零提问
- 先结构化再润色，避免把不该对外的细节写漂亮
- 多模态吃材料，指标/项目/资质必须人工核对
- 一种主稿、多种出口（口播 / 一页纸 / 电梯演讲 / FAQ）
- 成功结构沉成 Skill / Rules，个人效率变团队效率
